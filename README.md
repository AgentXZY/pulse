# PULSE

**Your workspace. Your projects. Your momentum.**

PULSE is a modern project management workspace designed to help individuals and teams organize projects, manage tasks, track progress, and improve productivity.

## Features

- Project creation and management
- Task creation, assignment, and tracking
- Kanban board for visual task management
- Task priorities and deadlines
- Team collaboration
- Project progress analytics
- Activity tracking

## Tech Stack

**Backend**
- Java
- Spring Boot
- Spring Data JPA
- Spring Web

**Frontend**
- HTML5
- CSS3
- JavaScript

**Database**
- H2 Database

## Project Status

🚧 Currently under development.

## Getting Started

1. Clone the repository.
2. Open the project in Eclipse.
3. Import it as an existing Maven project.
4. Run the `PulseApplication` class.
5. Access the application at `http://localhost:8080`.
